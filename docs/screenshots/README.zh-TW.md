## 怎麼做出來的

畫面上沒有任何真實資料，全部來自一套用完就丟的示範環境：

- 一套從這個儲存庫建置、獨立的 Telepy，有自己的連接埠與資料。
- 九個扮演裝置的 Debian 容器，每個都用真正的一行指令加入。
- 一個由小容器組成的辦公室網路，帶著真實的廠牌 MAC 前綴，透過 `office-gw` 掃描。
- 使用者、標籤、群組、分享、規則、指令片段、token、MCP 呼叫與終端機連線，全部像真人一樣透過 API、MCP 和終端機建立。

位址都取自保留給文件使用的範圍：裝置用 `203.0.113.x`，訪客用 `198.51.100.x`，伺服器叫 `telepy.example.com`。每台裝置回報的記憶體、運作時間與負載都是假的，所以裝置狀態不會只是示範機器自己的數字。不過伺服器狀態上的磁碟數字是真的——那個我們實在不忍心造假。

## 拍攝方式

- 無頭 Chromium（Playwright）、淺色主題、時區 Asia/Taipei。
- 1680 × 1050、2 倍縮放（通道頁為 1680 × 1260），再縮成 1920 px 寬，存成調色盤 PNG。
- 介面改到截圖會誤導人時，三種語言都要重拍，讓各語言的 README 保持一致。
