## 製作方式

截圖裡的一切都是用完即丟的示範資料，不是真實資料：一套從儲存庫建置的獨立 Telepy 環境（有自己的 `PROJECT_NAME`、連接埠與資料目錄）、九個以真正的一行指令加入的 Debian 容器作為裝置、一個由小型容器組成的 `office.lan` 網路（帶有真實的廠商 MAC 前綴，取自 IEEE OUI 清單）並透過 `office-gw` 掃描，而使用者、標籤、群組、分享、規則、片段、API token、MCP 呼叫與終端機工作階段，則是透過 REST API、MCP 端點與終端機 WebSocket 建立。公開位址取自文件專用的範圍：裝置使用 `203.0.113.0/24`（由假的查詢服務回答它們的公開 IP），訪客使用 `198.51.100.0/24`（以 X-Forwarded-For 送出，預設的 `auto` 代理規則會把它當成訪客位址），伺服器名稱為 `telepy.example.com`，每個裝置則透過掛載進去的 `/proc` 檔案回報自己的記憶體、運作時間與負載，所以裝置資訊並不是主機的。伺服器狀態畫面中的儲存空間數字是示範機器真實的磁碟。

截圖以無頭 Chromium（Playwright）拍攝，解析度 1680 × 1050（通道頁面為 1680 × 1260），裝置縮放比例 2，淺色主題，時區 Asia/Taipei，再縮放到 1920 px 寬並存成調色盤 PNG。

當介面改動大到截圖會造成誤導時，請把該畫面的三種語言版本全部重拍，讓各語言的 README 保持一致。

## 文件裡的圖解與錄影

`docs/images/<lang>/` 放的是各份文件內嵌的圖，同樣來自這套示範伺服器：每個說明對話框（路徑圖、時間軸、影響範圍圖）
由腳本打開後以 1440 px 寬、縮放比例 2 擷取，再縮到最寬 1200 px；GIF 則是真實操作過程的定時截圖（裝置執行一行指令、
刪除通道、遠端瀏覽器啟動、建立頁的網路圖、API 頁的「四種進入方式」、低調登入頁），用 sharp 以每秒約 8–10 格組成。
每種語言的檔名都一樣，所以某個對話框改了，三種語言都要重拍。
