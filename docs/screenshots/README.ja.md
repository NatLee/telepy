## 作り方

写っているものに実データはありません。すべて使い捨てのデモ環境から来ています。

- このリポジトリからビルドした、ポートもデータも別の Telepy。
- デバイス役の Debian コンテナ 9 台。どれも本物の 1 行コマンドで追加しています。
- 実在のメーカーの MAC プレフィックスを持つ小さなコンテナでできたオフィスネットワーク。`office-gw` 経由でスキャンします。
- ユーザー、ラベル、グループ、共有、ルール、スニペット、トークン、MCP 呼び出し、ターミナルのセッションは、人が操作するのと同じように API、MCP、ターミナルから作成しています。

アドレスはドキュメント用に予約された範囲から取っています。デバイスは `203.0.113.x`、訪問者は `198.51.100.x`、サーバーは `telepy.example.com` です。各デバイスが報告するメモリ、稼働時間、負荷は作りもので、デモマシン自身の数字がそのまま並ぶことはありません。ただしサーバーの状態に出るディスクの数字だけは本物です。さすがにそこまで偽る気にはなれませんでした。

## 撮影

- ヘッドレス Chromium（Playwright）、ライトテーマ、タイムゾーン Asia/Taipei。
- 1680 × 1050、2 倍スケール（トンネルのページは 1680 × 1260）で撮り、幅 1920 px に縮小してパレット PNG で保存。
- 画面が誤解を招くほど変わったら、3 言語とも撮り直して各 README をそろえます。

## ドキュメント内の図と録画

ドキュメントに載せている画像も同じデモサーバーから作っています。

- 説明ダイアログ（経路図、タイムライン、影響範囲の図）はスクリプトで開き、幅 1440 px・2 倍スケールで撮影してから最大 1200 px に縮小。
- GIF は実際の操作を一定間隔で撮ったものです。デバイスで 1 行のコマンドを実行する、トンネルを削除する、リモートブラウザを起動する、など。毎秒 8〜10 コマほどです。
- ファイル名はどの言語でも同じなので、ダイアログが変わったら 3 言語とも撮り直します。
