## 作り方

画面に写っているものはすべて使い捨てのデモで、実データではありません。リポジトリからビルドした別の Telepy スタック（専用の `PROJECT_NAME`、ポート、データディレクトリ）、実際の 1 行コマンドで参加させたデバイス役の Debian コンテナ 9 台、実在のベンダー MAC プレフィックス（IEEE OUI リスト）を持つ小さなコンテナで作った `office.lan` ネットワーク（`office-gw` 経由でスキャン）を用意し、ユーザー、ラベル、グループ、共有、ルール、スニペット、API トークン、MCP 呼び出し、ターミナルセッションは REST API、MCP エンドポイント、ターミナルの WebSocket を通して作成しています。パブリックアドレスにはドキュメント用の範囲を使っています。デバイスは `203.0.113.0/24`（偽のルックアップがパブリック IP の問い合わせに答えます）、訪問者は `198.51.100.0/24`（X-Forwarded-For として送られ、デフォルトの `auto` プロキシルールが訪問者として扱います）、サーバー名は `telepy.example.com` です。各デバイスは bind マウントした `/proc` ファイルでメモリ、稼働時間、負荷を自分で報告するため、デバイス情報はホストのものではありません。サーバーの状態の画面にあるストレージの数値は、デモマシンの実際のディスクです。

撮影はヘッドレス Chromium（Playwright）で、解像度は 1680 × 1050（トンネルのページは 1680 × 1260）、デバイススケールファクター 2、ライトテーマ、タイムゾーン Asia/Taipei で行い、幅 1920 px にリサイズしてパレット PNG として保存しています。

インターフェースの変更で画面が誤解を招くほど変わったときは、その画面の 3 言語分をすべて撮り直し、各言語の README が揃った状態を保ってください。

## ドキュメント内の図と録画

`docs/images/<lang>/` には各ドキュメントに埋め込む画像があり、同じデモサーバーから作っています。説明ダイアログ
（経路図、タイムライン、影響範囲の図）はスクリプトで開き、幅 1440 px・スケール 2 で撮影してから最大 1200 px に縮小
しています。GIF は実際の操作を一定間隔で撮ったものです（デバイスで 1 行のコマンドを実行、トンネルの削除、リモート
ブラウザの起動、作成ページのネットワーク図、API ページの「4 つの入り口」、目立たないサインイン画面）。sharp で毎秒
約 8〜10 コマにまとめています。ファイル名はどの言語でも同じなので、ダイアログが変わったら 3 言語とも撮り直します。
