# Fonts, favicon, mascot, disclaimer, sponsoring

## Fonts

- **Sans (CJK + Latin):** jf-openhuninn 2.1 / 粉圓 (justfont, SIL OFL; source `src/frontend/src/fonts/jf-openhuninn-2.1.ttf`) — the whole UI font, family name `"jf-openhuninn"` in `--font-sans`
- **Monospace (UI):** 0xProto Nerd Font (`src/frontend/src/fonts/0xProtoNerdFont-Regular.woff2`) — `font-mono`; still one of the terminal choices
- **Terminal:** the user's choice (see **Terminal appearance** in `terminal.md`), **Hack Nerd Font Mono by default**. The choices are the Nerd Fonts v3.5.1 **Mono** cuts (icons one cell wide) in `src/frontend/src/fonts/terminal/` — Hack, JetBrains Mono, Fira Code, Cascadia Code (CaskaydiaCove), Meslo LGS — as Regular **plus the real Bold / Italic / Bold Italic faces** (Fira Code has no italic) with their licenses, the faces-per-family table and the conversion command in that folder's `README.md` (licenses are `.md` because `.gitignore` drops `*.txt`). `src/app/terminal-fonts.css` declares every face under one family name with `local()` first, so an installed copy skips the ~1.2 MB download, and the browser fetches only the faces a terminal draws text with (Bold on the first bold cell, Italic on the first italic one). 0xProto's Bold / Italic (`src/fonts/0xProtoNerdFont-{Bold,Italic}.woff2`, no Bold Italic) are extra `src` entries of the same next/font family in `layout.tsx`, so `font-mono` UI text gets them too
- **Huninn is split into `unicode-range` subsets** by `src/frontend/scripts/subset-huninn.py` (needs `pip install fonttools brotli`; run from `src/frontend`): `src/fonts/huninn/ui.woff2` (~230KB: Latin, punctuation and every non-ASCII character found in `src/**/*.ts(x)` — i.e. all UI text) plus `cjk-NN` / `misc-NN` slices for the rest, and the generated `src/app/huninn.css` (`@font-face` rules, imported by `layout.tsx`; Next bundles the `url()`s as hashed, immutable assets). The browser downloads only the slices a page actually shows, so huninn appears almost immediately instead of after the old 2.2MB file. **Re-run the script after adding UI text with new CJK characters** (unlisted characters still render — they just come from a cjk slice). `ui` is declared last on purpose: with overlapping ranges the last face wins.
- 0xProto still loads via `next/font/local` in `layout.tsx` with `display: "swap"` **and `preload: false`** (next/font would otherwise preload it on every route and compete with the JS that gates interactivity). Never use `display: block` — it blanks text until the font arrives.
- **Form fields use `jf-openhuninn-field`** (same files, `ascent-override: 92%` / `descent-override: 26%`; emitted by `subset-huninn.py` as `FIELD_FAMILY`, applied to `input, textarea, select` in `globals.css`): huninn declares a descent of ~0.13em while g / j / p / q reach ~0.24em, and Chrome clips text inside form fields to the declared box, which cut descenders and made field text sit low. Other text keeps the original metrics.
- **Huninn has a single weight (400). `body` sets `font-synthesis-weight: none`** because faux bold smears its rounded strokes until it looks like the system font (this was the "it isn't huninn" complaint). Build hierarchy from size and colour, not `font-semibold`/`font-bold` (they render as regular). `<strong>` is styled as a highlighter mark instead of bold. `.xterm` opts back into synthesis for bold terminal cells.
- `--font-mono` keeps `ui-monospace, 'Courier New', monospace` as fallback; `--font-sans` falls back to `ui-sans-serif, system-ui, sans-serif`. No Geist dependency.
- xterm.js awaits `document.fonts.load()` for the chosen terminal font (1.5s timeout guard) before creating a shell — it does not depend on the CJK font. A font that loads after the timeout makes `useTerminalPage` re-measure (xterm only re-measures when `fontFamily` changes, hence a `monospace` round trip). The 0xProto choice reads its next/font family from `--font-0xproto` via `getComputedStyle(document.body)`
- If a change to `globals.css`'s `@theme` seems ignored in `next dev`, delete `src/frontend/.next` — Turbopack can keep serving the previously compiled Tailwind theme.

## Favicon

- `src/frontend/src/app/icon.svg` is the source: brand-gradient tile (the fixed amber-orange `#e3770e` → persimmon `#c04815` of `.bg-brand-gradient`, same in both themes) + a white "reverse tunnel" hairpin (dot → out → U-turn → arrow back). 64-unit grid, stroke 8, horizontal strokes on multiples of 4 so 16/32px stay pixel-sharp. Next.js file conventions emit the `<link>` tags.
- `favicon.ico` (16/32/48 PNG entries) and `apple-icon.png` (180×180, full-bleed — iOS masks the corners) are rendered from it with `sharp` (in the frontend's `node_modules`); re-render both whenever the SVG or the brand colours change. The installable app's icons (`public/icons/`, incl. the full-bleed maskable one with the glyph in the 80 % safe zone) come from `node scripts/app-icons.mjs`; re-run it too. Never put a double hyphen inside the SVG comment (invalid XML → broken icon).
- The Swagger shell (`api/doc.rs`) links the same `/favicon.ico` + `/icon.svg`. In the UI the same glyph is `components/brand/TelepyGlyph.tsx` (strokes in currentColor, typed as a `LucideIcon`, drawn on a `bg-brand-gradient` tile): sidebar `BrandMark`, the login diagram, the wizard's Telepy node and the command sheet's tunnel chip. Use it wherever *Telepy itself* is shown; lucide `Cable` stays only as the generic "connect" icon.
- Brand assets for the README / GitHub live in `docs/brand/` (`logo.svg`, `logo-lockup.svg` + `-dark.svg`, `banner.svg` + `banner.png` 1280×640 = GitHub social preview, uploaded by hand in the repo settings), generated by `src/frontend/scripts/brand-assets.py` with the text outlined from jf-openhuninn; re-run it when the glyph, colours or tagline change.

## Mascot, disclaimer, sponsoring

- **Easter eggs + Tapi, the mascot (`mascot.rs` + `src/frontend/src/lib/mascot.ts`, same grids — `mascot.test.ts` reads the Rust file; `components/brand/Tapi.tsx`, `hooks/useTapi.ts`, `lib/festivals.ts`, `lib/credits.ts`, `components/brand/{AboutTelepy,ConsoleHello}.tsx`, `app/not-found.tsx`, `components/layout/BrandMark.tsx`; tests `mascot.test.ts`, `festivals.test.ts`, `credits.test.ts`, `tunnelQuery.test.ts`, `tapi_color` in `tests/rest_api.rs`):** Tapi is a little persimmon-orange pixel ghost (no feet, line eyes, ω mouth) with a pixel cross clip on each ear; it **only appears in easter eggs**, never in ordinary UI (empty states etc.). Eggs: the 404 page (Tapi startled above a pixel portal), seven clicks on the sidebar logo (`playful` BrandMark only — never on sign-in / enrolment screens: the glyph redraws and a "You found me" card), Lunar New Year (`Intl` `ca-chinese`, eve → 15th: a persimmon calyx on the logo tile + 柿柿如意 tooltip) and Telepy's birthday 18 Feb (party hat), a sub-millisecond latency tooltip line, `sudo make me a sandwich` in the tunnel search (`ParsedQuery.reply`, filters nothing), a devtools console greeting, and Preferences → General → About Telepy (clicking 粉圓 throws ender-pearl-style pixel pearls; Credits = a generated asciicast in `CastPlayer`: the **contributors come first** (`CREDIT_LINES.contributors`, GitHub contribution order — add new people there), original pixel art above sections (`CREDIT_ART`: heart / bubble tea / browser / server, plus the big Tapi) drawn as background-coloured spaces, one pixel = two columns × one row (▀▄ half blocks leave seams in xterm's DOM renderer; when the player is scaled down, `CastPlayer pixelArt` adds `.cast-pixel-art` so cells overlap the next row by 1px), and a finale per viewer decided on open (`tapiFinale`): `shadow` = no Tapi yet → a silhouette, the mascot named `???`, a riddle under the thank-you and, at the end, a footer hint to click the logo; the daily colour is still saved (banked), so the found card says so (`eggs.found.banked`) and About shows `about.tapiWaiting` meanwhile; `unlock` = the clips cycle through every colour; `owned` = Tapi's own colour). **Tapi's clip colour is an account setting** (`user_management_usersettings.tapi_color`, also in the profile): empty = Tapi not found yet; finding it via the logo sets `teal` and unlocks "Your Tapi" in About (six colours, `mascot::CLIP_COLORS`); watching the credits to the end sets `tapi_daily` and unlocks `daily` (the colour rotates by UTC day, `mascot::clip_name` / `lib/mascot.clipName`, so web, gateway greeting and CLI agree; `daily` is refused until unlocked). The web keeps both in `lib/tapiStore.ts` (tested), not the auth context: `UserSettingsSync` seeds it from every profile, a save shows at once, rapid clicks coalesce into ordered POSTs, the server's answer wins and a failure reverts — never refetch the profile for a Tapi change (replacing `user` re-rendered the whole page and made picking a colour feel stuck). Festive outfits (red crosses with gold centres at Lunar New Year, a party hat on the birthday, a bedsheet with eye holes and the orange hem showing at Halloween, 31 Oct — the ghost dresses up as a ghost; the logo tile then has the sheet-Tapi sitting on it) are web-only (`dressTapi`). **Tapi's visits (`components/brand/TapiVisits.tsx` in AppLayout, rules pure + tested in `lib/tapiCameos.ts`):** Tapi stays out of ordinary UI (the user found empty-state appearances too much), so besides the eggs above it only (1) **peeks** up from the bottom edge for 6.5 s on a calm page (`calmPage`: lists / logs / keys / CLI / API / MCP — never terminal, desktop, network, files, watch, the wizard), after 45–150 s with no typing for 20 s, no dialog and the tab visible; `peekDue`: at most once every 3 days and only on a lucky day (`luckyDay`, fixed per browser salt + day, ~50 %), guaranteed once on a festival day, never with reduced motion or with the account setting `tapi_visits` off (`user_management_usersettings.tapi_visits`, default on, About → Your Tapi switch); clicking it "catches" Tapi (unlocks it like the logo for those who hadn't found it); searching `tapi` / `where is tapi?` in the tunnel search (`ParsedQuery.reply = "tapi"`) calls a peek at once; (2) the Konami code flies the side-view Tapi across the screen; (3) one cheer when a tunnel is verified (wizard step 5 / one-command join), once per browser and only after Tapi was found.
